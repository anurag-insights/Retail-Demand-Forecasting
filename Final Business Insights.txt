FINAL BUSINESS INSIGHTS

RETAIL DEMAND FORECASTING

Business Name: Evergreen Mart

PROJECT OVERVIEW

This project focuses on developing a machine learning based retail demand forecasting system for a fictional retail business named Evergreen Mart.

The main objective is to analyze historical daily sales data and build predictive models that can estimate future product demand.

Accurate demand forecasting can help retail businesses make better inventory decisions, reduce the risk of overstocking and stockouts, and improve business planning.

This project uses a synthetic dataset representing one retail store and one beverage product.


BUSINESS PROBLEM

Retail businesses often face challenges when estimating how much inventory they need to meet future customer demand.

Ordering too much inventory can increase storage costs and lead to unsold products. Ordering too little can result in stockouts and missed sales opportunities.

Evergreen Mart needs a reliable way to estimate daily product demand using historical sales information and other relevant factors.

The main business question is how Evergreen Mart can use historical sales data and machine learning techniques to predict daily product demand and support better inventory planning.


PROJECT OBJECTIVES

The main objectives of this project were to analyze historical retail sales data, identify and handle data quality issues, explore sales patterns, create useful features, develop machine learning models, evaluate model performance, select the best performing model, and provide practical recommendations for inventory planning.


DATASET OVERVIEW

The project uses a synthetic retail dataset containing approximately 200 daily observations and 12 original columns.

The dataset represents one fictional retail store and one beverage product.

The dataset includes the following important variables.

Date

Store_ID

Product_ID

Product_Category

Units_Sold

Unit_Price_NPR

Discount_Pct

Promotion

Day_of_Week

Is_Holiday

Inventory_Level

Weather

The dataset intentionally contains several data quality issues to simulate challenges commonly found in real world retail data.

These issues include missing values, inconsistent labels, mixed date formats, duplicate dates, invalid numerical values, and unusual sales observations.

The dataset is artificially generated and does not represent actual sales records from a real business.


DATA CLEANING AND PREPROCESSING

The raw dataset was inspected and cleaned before performing exploratory data analysis and model development.

The following activities were performed.

Inspected the dataset structure, data types, and missing values.

Converted numerical columns into appropriate numerical data types.

Standardized inconsistent categorical values.

Converted date values into a consistent date format.

Inspected and handled duplicate records and dates.

Identified invalid numerical values.

Checked sales, prices, discounts, inventory levels, and holiday indicators for invalid values.

Handled missing explanatory variables using appropriate preprocessing techniques.

Preserved missing target values instead of blindly filling missing sales values.

After cleaning, the dataset contained 6 missing values in the Units_Sold column and 0 negative sales values.

Rows with missing target values were excluded from supervised model training and evaluation because actual sales values are required to calculate forecasting errors.

The cleaned dataset was saved for further analysis.


EXPLORATORY DATA ANALYSIS

Exploratory Data Analysis was performed to understand the structure and behavior of the retail sales data.

The following analyses and visualizations were created.

Sales distribution analysis.

Sales outlier analysis.

Daily sales trend analysis.

Seven day moving average analysis.

Average sales by weekday.

Average sales by month.

Promotion versus sales analysis.

Price versus sales analysis.

Inventory versus sales analysis.

Correlation analysis of numerical variables.

These visualizations helped examine sales distributions, time based patterns, promotional activities, pricing, inventory levels, and relationships among numerical variables.

The analysis provided a foundation for feature engineering and model development.

The dataset covers a relatively short period. Therefore, it is not sufficient to establish reliable long term annual seasonality or recurring yearly demand patterns.


FEATURE ENGINEERING

Feature engineering was performed to create additional variables that could help machine learning models identify useful patterns in historical sales data.

Calendar features included Year, Month, Day, Day_of_Week_Number, Is_Weekend, and Week_of_Year.

Lag features included Sales_Lag_1, Sales_Lag_7, and Sales_Lag_14.

These features represent historical sales from one, seven, and fourteen days earlier.

Rolling features included Rolling_Mean_7 and Rolling_Mean_14.

These features represent recent historical sales averages over seven day and fourteen day periods.

A one period shift was applied before calculating rolling averages to ensure that the current day's sales were not used to predict the same day's demand.

The engineered dataset was saved for model development.


MODEL DEVELOPMENT

Four forecasting approaches were evaluated in this project.

Linear Regression

Linear Regression was used as an initial machine learning model to establish a basic relationship between input features and daily sales.

Random Forest Regressor

Random Forest was used to capture potentially complex relationships between sales and the available input features.

Gradient Boosting Regressor

Gradient Boosting was used as an ensemble learning approach that builds models sequentially to improve predictive performance.

Naive Baseline

A simple baseline model was created using the previous day's sales as the prediction for the current day.

This baseline was used to determine whether machine learning models could perform better than a simple forecasting approach.

The dataset was divided chronologically into 80 percent training data and 20 percent testing data.

A chronological split was used instead of a random split because the project involves time series forecasting.

Categorical and numerical variables were processed using appropriate preprocessing techniques.


MODEL PERFORMANCE EVALUATION

The models were evaluated using three regression metrics.

Mean Absolute Error measures the average absolute difference between actual and predicted sales.

Root Mean Squared Error measures prediction errors while giving greater importance to larger errors.

Weighted Absolute Percentage Error measures total absolute prediction error relative to total actual sales.

The model comparison results were as follows.

RMSE: 9.29

WAPE: 16.56 percent


Random Forest

WAPE: 21.02 percent


Linear Regression

MAE: 75.99

Naive Baseline

MAE: 8.53

RMSE: 10.17

WAPE: 18.29 percent


BEST PERFORMING MODEL

Gradient Boosting achieved the best overall results among the evaluated approaches.

Its performance was as follows.

MAE: 7.74 units

RMSE: 9.29 units

WAPE: 16.56 percent

This means that its predictions differed from actual daily sales by approximately 7.74 units on average.

Gradient Boosting also performed better than the Naive Baseline.

The Naive Baseline achieved an MAE of 8.53, while Gradient Boosting achieved an MAE of 7.74.

This represents an approximately 9.2 percent reduction in MAE compared with the Naive Baseline.

Random Forest also performed better than Linear Regression.

Based on these evaluation results, Gradient Boosting was selected as the best performing machine learning model for this project.


PREDICTION BIAS ANALYSIS

Prediction bias was calculated using the difference between predicted sales and actual sales across the 39 test observations.

The formula used was the average of predicted sales minus actual sales.

The Gradient Boosting model achieved a mean prediction bias of negative 3.52 units.

The prediction bias results were as follows.

Mean Prediction Bias: Negative 3.52 units

Overpredicted Days: 9

Underpredicted Days: 30

Total Test Observations: 39

Total Actual Sales: 1823 units

Total Predicted Sales: Approximately 1685.88 units

The negative prediction bias indicates that the Gradient Boosting model tends to underestimate actual daily sales.

On average, the model predicts approximately 3.52 fewer units per day than actual sales.

The model underestimated sales on 30 out of 39 test days and overestimated sales on 9 days.

This behavior is important because consistent underprediction may lead to insufficient inventory if forecasts are used directly for replenishment planning.

Evergreen Mart should regularly compare actual sales with predicted sales and investigate periods with significant underprediction.

The business may also consider an appropriate inventory buffer based on forecast errors, supplier lead times, and desired service levels.

However, the business should not automatically increase every forecast by 3.52 units. Any forecast adjustment should be tested using additional historical data and future forecasting evaluations.


FORECASTING ERROR ANALYSIS

A detailed forecasting error analysis was performed using the 39 test observations to identify dates with the largest differences between actual and predicted sales.

The results were as follows.

Mean Absolute Error: 7.74 units

Median Absolute Error: 6.83 units

Largest Absolute Prediction Error: 21.06 units

The largest overprediction occurred on October 6, 2025.

On this date, actual sales were 49 units while predicted sales were approximately 70.06 units.

The largest underprediction occurred on October 2, 2025.

On this date, actual sales were 58 units while predicted sales were approximately 41.01 units.

The analysis showed that the model does not perform equally well across all test observations. Some dates have substantially larger prediction errors than others.

These results suggest that certain sales patterns or business conditions may be difficult for the model to predict accurately.

Evergreen Mart should investigate dates with unusually large forecasting errors by examining promotional activities, pricing changes, inventory availability, weather conditions, and recent sales patterns.

Understanding these factors may help identify opportunities to improve forecasting accuracy.

However, the available error analysis alone does not establish the causes of individual prediction mistakes. Further investigation using the corresponding business features is required.


BUSINESS INSIGHTS AND RECOMMENDATIONS

Based on the forecasting objective, model performance, prediction bias, and forecasting error analysis, the following recommendations could help Evergreen Mart improve its inventory planning process.

Use Forecasts to Support Inventory Planning

Evergreen Mart can use predicted daily demand as an additional input when planning future inventory requirements.

Forecasts should be considered alongside current inventory, supplier lead times, and expected customer demand.

Monitor Actual Sales Against Predicted Sales

The business should regularly compare actual sales with predicted sales.

Monitoring these differences can help identify periods when the forecasting model performs poorly and may require further improvement.

Since the model showed a tendency to underestimate demand, particular attention should be given to days with substantial underprediction.

Review Promotional Activities

Promotions and discounts may influence customer purchasing behavior.

The business should continue monitoring promotional periods and collect more historical promotional data to understand their relationship with demand.

Monitor Inventory Levels

Inventory information should be considered when making replenishment decisions.

However, inventory availability and actual customer demand are not always the same. Low inventory can restrict sales, meaning recorded sales may underestimate true customer demand.

Consider Forecasting Bias During Replenishment

The negative average prediction bias suggests that the model tends to forecast fewer units than actual sales.

Evergreen Mart should monitor this behavior and investigate whether an inventory buffer or forecast adjustment is appropriate.

Any adjustment should be validated before implementation to avoid unnecessary overstocking.

Improve the Forecasting System Over Time

The forecasting model should be evaluated regularly using new sales observations.

As more historical data becomes available, the business can retrain models and compare their performance to determine whether forecasting accuracy improves.

These recommendations describe potential business applications. This project has not measured actual reductions in inventory costs, stockouts, or product wastage.


PROJECT LIMITATIONS

Although the project demonstrates a complete retail demand forecasting workflow, it has several limitations.

Synthetic Dataset

The dataset is artificially generated and does not represent actual retail transactions.

Limited Observations

Approximately 200 observations are not sufficient to establish reliable long term demand patterns.

Single Store

The project considers only one fictional retail store.

Single Product

The analysis focuses on one beverage product rather than multiple product categories.

Limited Historical Period

The available data does not provide enough history to establish annual seasonality or long term trends.

Model Generalization

Good performance on this test dataset does not guarantee similar performance on real world retail data.

Inventory Constraints

The dataset does not provide a complete record of stockouts, supplier lead times, or lost sales. Therefore, actual unmet customer demand cannot be measured reliably.

Forecasting Scope

The evaluation focuses on the available test observations and does not establish performance across multiple stores or products.

Prediction Bias

The selected model showed a tendency to underestimate sales on the test observations. This behavior should be investigated and monitored before using forecasts for real inventory decisions.

FINAL CONCLUSION

This project demonstrates an end to end machine learning workflow for retail demand forecasting.

It covered data quality assessment, data cleaning, exploratory data analysis, feature engineering, model development, and model evaluation.

Four forecasting approaches were compared: Linear Regression, Random Forest, Gradient Boosting, and a Naive Baseline.

Among these approaches, Gradient Boosting achieved the best performance, with an MAE of 7.74, RMSE of 9.29, and WAPE of 16.56 percent.

It also improved upon the Naive Baseline by reducing MAE by approximately 9.2 percent.

The prediction bias analysis showed that Gradient Boosting had a mean bias of negative 3.52 units, indicating a tendency to underestimate daily sales across the test observations.

The forecasting error analysis also identified dates where the model made larger prediction mistakes, highlighting opportunities for further investigation and improvement.

These findings demonstrate how historical sales patterns and additional business related features can be used to build a machine learning model for daily demand prediction.

Although the results are based on a small synthetic dataset, the project provides a foundation for developing more advanced retail forecasting systems using larger and more realistic business datasets.
